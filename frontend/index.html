About this viewer

AgentLens evaluates AI agents on task success, tool-call accuracy, escalation behaviour, latency, cost and safety — from recorded traces. This dashboard renders any AgentLens report.json; the demo report is bundled so it works offline. Token usage is shown only when traces record it — AgentLens traces currently record latency and cost, so the token KPI reports “not recorded” rather than inventing numbers.
